# NEXORA Career GPS, Career Guidance, Academic Reliability Update — 13 Oct 2026

## Implemented

- Development GPS now focuses on the three requested blocks: the calculated GPS percentage at the top, career-specific milestones in the middle, and the placement-readiness planner at the bottom.
- The GPS percentage is calculated from the stored milestone completion counts and is 0% until a real career target is selected. It updates when the student saves new evidence/course progress and reloads the page.
- On-campus planning displays the provided CORE/TRY planner criteria when available, with a clearly labelled general preparation checklist as a fallback.
- Off-campus planning first looks for verified company + role + programme + year-of-passing criteria. When no verified employer criteria are indexed, it shows career-role skills and preparation checkpoints clearly labelled as NEXORA guidance, not employer requirements.
- Career Guidance opening page now shows roles related to the saved career target in addition to the career families, occupation cross-check, role catalogue, skills, employers and location sections.
- Recommended Courses shows a completion percentage for the selected career's tracked learning resources; the number is derived from the student's saved statuses.
- Achievements are grouped into Hackathon, Workshop, Internship, Certification, Course completion, Project, Competition and Other folders. Only actual stored records are shown; empty folders are not filled with fabricated student achievements.
- Academic subject learning-material reads now use the short-lived page cache; empty results receive only a short negative-cache window to avoid repeated database calls during rapid retries.
- Academic subject/unit topic handling is more defensive against missing/null topic rows, which can otherwise trigger request-rendering errors.
- Fixed the Learning Materials Drive-sync URL to be generated by Thymeleaf on the button instead of relying on an unprocessed JavaScript placeholder.
- Suppressed a stale “choose a career” validation banner when the currently selected on-campus path does not require a career role.
- Clarified that LinkedIn refresh can only sync profile fields exposed by the configured/approved API scopes.

## Data integrity and provider limitations

- Employer eligibility, salaries, vacancies and achievement records are not invented. If no verified employer criterion exists, the planner shows a labelled preparation benchmark rather than pretending it came from a company.
- LinkedIn's basic OAuth/OpenID profile access does not grant access to all public posts, certificates, internships or learning history. Those imports require separate approved LinkedIn API permissions/products. NEXORA does not create fake achievements or use fabricated progress to inflate GPS.
- LeetCode, HackerRank, CodeChef and Kaggle remain external links unless a supported, authorized API connector is configured. Neopat progress is not claimed as automatic without an official provider API.
