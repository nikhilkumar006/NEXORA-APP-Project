Codeforces automatic problem sync

Codeforces exposes a documented public API for a handle’s submissions. Enter your handle once; NEXORA verifies it and imports accepted problem URLs. The initial backfill examines up to 10,000 recent submissions; a scheduled hourly refresh catches new accepted submissions while respecting the API rate limit.
